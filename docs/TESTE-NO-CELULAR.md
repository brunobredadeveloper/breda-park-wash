# Roteiro de avaliação
1. Cadastre Ana, placa ABC1D23, HB20 prata.
2. Registre entrada por diária. Outra entrada para o mesmo veículo deve ser bloqueada.
3. Altere a tarifa em Configurações. A estadia já aberta deve manter o preço anterior.
4. Confirme saída após receber, informando Pix/dinheiro/cartão. Consulte o Caixa.
5. Registre uma mensalidade, entre como mensalista, saia sem cobrança adicional.
6. Crie lavagem, avance para Em lavagem, Pronto e Entregue. Só a entrega registra valor no caixa.
7. Feche e reabra o aplicativo. Registros devem persistir.
8. Teste capacidade 1 e entrada de outro veículo enquanto ocupado.

A seleção de Pix ou cartão não faz transação bancária. Não inserir dados reais de clientes na avaliação. O projeto ainda não tem backup.
